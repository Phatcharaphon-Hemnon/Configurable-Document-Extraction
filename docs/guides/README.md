# Guides — setup and how-to

How to configure, run, and evaluate the system. Start with `ai_provider.md`.

| Guide | Covers |
|---|---|
| `ai_provider.md` | The 3 variables (`LLM_PROVIDER` / `LLM_API_KEY` / `LLM_MODEL`) that control the whole pipeline |
| `llm_providers.md` | Provider registry (base URLs, key vars, defaults, strict-JSON support) |
| `local_ocr.md` | Local OCR engines (Tesseract default; RapidOCR / hybrid opt-in) |
| `multilingual_ocr.md` | Multilingual (English/Thai) OCR notes |
| `thai_catalog_hybrid_ocr.md` | Thai catalogs + CPU hybrid OCR (opt-in) |
| `evaluation.md` | Gold-set release evaluation |
| `api_scripts.md` | Operator scripts: eval, gateway probe, OCR benchmark, review audit |
| `temporal.md` | Temporal durable-workflow mode (optional) |
| `langfuse_tracing.md` | Langfuse LLM observability |
| `cloudflare-tunnel-demo.md` | Cloudflare Tunnel demo notes |
