## Confirmed cause: upstream model retirement (availability, not config)

Groq's own deprecation notice
([deprecations](https://console.groq.com/docs/deprecations),
"August 16, 2026: `llama-3.1-8b-instant` and `llama-3.3-70b-versatile`"):
announced 2026-06-17, shut down **08/16/26** (past), replacement
`openai/gpt-oss-20b`; applies to free and developer-tier usage
(enterprise committed-spend contracts excepted — not applicable here).
Catalog absence alone was not treated as proof; combined with the official
notice, retirement is established. No endpoint/config mismatch (URL valid,
routing coherent) and no code defect demonstrated — nothing to fix in code.

still points at the retired ID and Router calls will keep 404ing.
Recommended next step (requires explicit authorization): set
